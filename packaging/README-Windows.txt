Disclosure Alpha for Windows
============================

1. Extract this entire ZIP folder somewhere writable, such as Downloads.
2. Double-click "Disclosure Alpha.exe".
3. Your default browser opens the filing review UI.
4. On first launch, enter your name and contact email. The SEC requires this
   contact information for live EDGAR filing lookups.

No Python, Node.js, installation, or terminal is required.

Settings and SEC filing cache are stored for the current Windows user in:
  %LOCALAPPDATA%\Disclosure Alpha

The application needs an internet connection for live ticker filings. Close the
browser tab to stop the local application shortly afterwards; opening the EXE
again starts it again.
